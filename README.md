# 🛍️ App Lista de Compras Inteligente – Android

Aplicativo Android moderno que permite selecionar produtos e calcular o total da compra em tempo real. Ideal para eventos, feiras ou uso pessoal no controle de itens.

---

## ⚙️ Recursos do Aplicativo

- ✅ Seleção de produtos com preços fixos
- 🧮 Cálculo automático do valor total
- ✨ Feedback visual suave ao calcular
- 💡 Interface responsiva, leve e acessível
- 🧩 Código limpo, ideal para aprendizado

---

## 📱 Interface do Usuário

Construída com foco em simplicidade e clareza, a tela contém:

- **Checkboxes** para itens como arroz, leite, carne etc.
- **Botão de cálculo** estilizado
- **Animação suave** ao exibir o total
- Design adaptável para diferentes tamanhos de tela

---

## 🧰 Tecnologias Aplicadas

- **Linguagem:** Java
- **IDE:** Android Studio
- **Layout:** XML com `ScrollView` e `LinearLayout`
- **Animação:** `AlphaAnimation` no total calculado
